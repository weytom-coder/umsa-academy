🧩 Mont-Blanc

Praxisfall zu Copper Card / Port Change (Reason ID 54).

📖 Situation

Ein Anschluss muss innerhalb der bestehenden Copper-Technologie auf einen anderen Port oder eine andere Karte verschoben werden.  

Der Kunde bleibt auf derselben Technologie, trotzdem hat der Wechsel Auswirkungen auf Systeme, Planung und Kommunikation.

❓ Aufgabe

Analysiere den Fall und beantworte:  

  • Warum wird der Wechsel durchgeführt?
  • Welche Systeme sind beteiligt?/li>
  • Welche Reason ID wird verwendet?
  • Welche Kundenwirkung besteht?

 

🔍 Leitfragen

  • Welcher technische Trigger besteht?
  • Welche Reason ID wird verwendet?
  • Welche Kommunikation wird ausgelöst?
  • Welche Systeme sind beteiligt?
  • Welche Risiken bestehen?

✅ Lösungsweg

1. NOVIS prüfen

  • Falltyp/li>
  • Termin
  • Maintenance Ticket

2. Reason ID prüfen

  • Reason ID 54
  • Copper Card / Port Change

3. Kommunikation prüfen

  • Avisierung
  • Termine
  • Kundenwirkung

4. Durchführung überwachen

  • Planung
  • Umsetzung
  • Abschluss

5. Dokumentation abschliessen

  • Ergebnis
  • Erkentnisse
  • Offene Fragen

📚 Lessons Learned

Nicht jeder technische Eingriff führt zu einem Technologiewechsel.  

Auch interne Anpassungen wie ein Card- oder Portwechsel müssen sauber geplant, kommuniziert und dokumentiert werden.  

Die Kundenwirkung entscheidet über die notwendige Kommunikation.

🚀 Mini Mission

Nimm einen realen oder fiktiven Mont-Blanc-Fall..
Dokumentiere:  

  • Reason ID
  • Trigger
  • beteiligte Systeme
  • Kundenwirkung
  • Abschluss
  Präsentiere den Fall in maximal 5 Minuten.
