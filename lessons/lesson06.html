Reason ID's und CAF Rule's

🎯 Lernziel

Reason IDs verstehen.
CAF Rules verstehen.
  Die Auswirkungen auf Verarbeitung, Reporting und Kundenkommunikation erklären.

📘 Lernkarten

📘 Was ist eine Reason ID?

Eine Reason ID beschreibt die Art eines Changes oder Ereignisses.  

Sie hilft den beteiligten Systemen, einen Fall korrekt einzuordnen und passende Prozesse auszulösen.

📘 Was ist eine CAF Rule?

Eine CAF Rule steuert in Netcracker CIA, wie ein Fall verarbeitet wird.
Sie beeinflusst unter anderem:  

  • Kundenkommunikation
  • Klassifizierung
  • Verarbeitung
  • Auswertungen

📘 Reason ID 21

Copper UMSA without Duration
Geplante Copper UMSA ohne hinterlegte Unterbruchsdauer

📘 Reason ID 22

Copper UMSA with Duration
  Geplante Copper UMSA mit hinterlegter Unterbruchsdauer.

📘 Reason ID 23

Copper UMSA Incident
  Im Gegensatz zu 21 und 22 handelt es sich um einen Incident-Fall.

📘 Reason ID 54

Copper Card / Port Change
  Diese Reason ID wird dem Mont-Blanc-Kontext zugeordnet.

📘 Warum Governance wichtig ist

Eine fehlerhafte Reason ID oder eine falsche CAF Rule kann folgende Auswirkungen haben:  

  • falsche Verarbeitung
  • fehlerhafte Reports
  • inkorrekte Kundenkommunikation
  • falsche KPI-Auswertung
  Darum müssen Definition, Owner und Änderungen klar geregelt sein.

📘 Detektivauftrag

Öffne einen realen Copper-Fall.
Finde:  

  • Reason ID
  • Bedeutung
  • CAF Rule
  • ausgelösteKommunikation
  Dokumentiere zusätzlich den verantwortlichen Owner.

🧠 Wissenscheck

Frage 1

Welche Reason ID steht für Copper Card / Port Change?

  • A) 23
  • B) 54 ✅
  • C) 72
  • D) 76
Erklärung:
Reason ID 54 steht für Copper Card / Port Change und gehört zum Mont-Blanc-Kontext.

Frage 2

Was unterscheidet Reason ID 23 von 21 und 22?

  • A) Fiber
  • B) Copper Incident ✅
  • C) Mont Blanc
  • D) Dauer
Erklärung:
  Reason ID 23 beschreibt einen Incident-Kontext.
  Reason ID 21 und 22 beschreiben geplante UMSA-Fälle.

Frage 3

Warum sind Reason IDs und CAF Rules kritisch?

  • A) Wegen der Farbe im System
  • B) Weil sie Verarbeitung, Reporting und Kommunikation steuern ✅
  • C) Wegen Benutzerrechten
  • D) Wegen Performance
Erklärung:
  Falsche Einstellungen können zu Fehlern in Kommunikation, Prozesssteuerung und Reporting führen.
