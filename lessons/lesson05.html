Praxisfall

🎯 Lernziel

Einen realen Copper-Fall von der Planung bis zum Abschluss verfolgen.
Die wichtigsten Systeme anhand eines echten Beispiels verbinden.
Input, Verarbeitung, Output und Kundenwirkung dokumentieren.

📘 Lernkarten

📘 Ziel des Praxisfalls

Du verfolgst einen echten Copper-Fall von der Planung bis zum Abschluss.  
Dabei dokumentierst du:  

  • Wo die Daten entstehen
  • Wo sie verarbeitet werden
  • Welche Systeme beteiligt sind
  • Welche Kundenwirkung entsteht

📘 Einen geeigneten Fall auswählen

Starte mit einem möglichst normalen Copper-Fall.
Später können komplexere Fälle bearbeitet werden:  

  • Terminverschiebung
  • Veto
  • Sync NOK

📘 NC-CIA analysieren

Prüfe:
 

  • Welche Daten übernommen wurden
  • Welche CAF Rule verwendet wird
  • Welche Kommunikation ausgelöst wird
  Verstehe die Verbindung zwischen Prozess und Kundenkommunikation.

📘 SEO analysieren

Prüfe:  

  • Events
  • Plan-Werte
  • Ist-Werte
    •  
Beantworte:  
  • Wann war die UMSA geplant?
  • Wann wurde sie durchgeführt?
  • Welche Abweichungen sind sichtbar?

📘 Handover und Kundenwirkung

Verfolge die Kommunikation:  

  • Vor dem Start
  • Während der Durchführung
  • Beim Abschluss
  Prüfe den Übergang von NC-CIA zu ComHub.

📘 Vier Perspektiven pro System

Für jedes System dokumentierst du:
Input, Verarbeitung, Output, Kundenwirkung

📘 Know How Check

Erkläre den Fall vollständig.
Beantworte:  

  • Welche Reason ID wurde verwendet?
  • Welche CAF Rule wurde verwendet?
  • Welche Kundenwirkung entstand?
  • Welche Besonderheiten gab es?

🧠 Wissenscheck

Frage 1

Welches System sollte als Erstes analysiert werden?

  • A) ComHub
  • B) NOVIS ✅
  • C) SEO
  • D) MySwisscom
Erklärung:
NOVIS bildet den UMSA-Prozess ab und dient als Ausgangspunkt des Praxisfalls.

Frage 2

Welche vier Perspektiven sollen dokumentiert werden?

  • A) Kosten, Zeit, Benutzer, Standort
  • B) Input, Verarbeitung, Output, Kundenwirkung ✅
  • C) System, Owner, Ticket, Dauer
  • D) Planung, Fehler, Ticket, Abschluss
Erklärung:
Diese vier Perspektiven zeigen den End-to-End-Datenfluss.

Frage 3

Welches Ziel hat der Praxisfall?

  • A) Systeme auswendig lernen
  • B) Menüs und Masken lernen
  • C) End-to-End-Verständnis aufbauen ✅
  • D) Nur die Kommunikation analysieren
Erklärung:
Der Praxisfall soll das Verständnis für den gesamten Daten- und Prozessfluss fördern.
